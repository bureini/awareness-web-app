# Message Awareness · AI Draft

A lightweight, client‑side web app that helps you draft messages with different tones (Professional, Friendly, Urgent, etc.) and share them via Twitter, WhatsApp, Email, or copy to clipboard.

## Features
- AI‑assisted tone rewriting (no external API – pure JavaScript)
- Live character counter
- Share via Web Share API or platform‑specific buttons
- Fully responsive

## Usage
Simply open `index.html` in any modern browser. No build or server required.

## Deployment
This app is hosted on GitHub Pages – https://bureini.github.io/awareness-web-app/
